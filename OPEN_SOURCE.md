# Attestara: open-source contract

Project source is public under [Apache-2.0](LICENSE). The full supported local core includes UI, engine, rules, synthetic examples, tests, build recipes and resource/provider instructions without paid/cloud accounts, proprietary entitlements or sibling repositories. package.json private=true only prevents accidental npm publication.

Upstream dependencies retain their own licenses. Pin/inventory libraries, providers/images, rules, grammars and datasets at C02/C31; include distributable notices and source-build instructions. Unknown/restricted resources cannot silently become required core dependencies. Optional hosted/commercial adapters cannot gate the local core. Do not commit private source, secrets, incident data or license-unknown examples.

The current implementation is the C30 single-operator local CLI/snapshot store
and browser-local passport viewer. C31 records local artifact/source reproduction;
C33 records browser/keyboard checks. Source-bound evidence and its limits remain
authoritative. Published OSS v1 is the pending C40 gate.

The [user guide](docs/release/USER_GUIDE.md) covers data, limits, privacy and
recovery. [ARTIFACTS.md](docs/release/ARTIFACTS.md) covers source builds, unsigned
local packages and bundled notices. Node is external; optional OPA/Syft/Grype
are not mandatory accounts. Contributing: CONTRIBUTING.md. Agent instructions:
AGENTS.md. Vulnerability reports/responses use GitHub via SECURITY.md; no
dedicated mailbox is required. The private route must actually be enabled
before C34 can be verified.
