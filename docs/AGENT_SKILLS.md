# Attestara agent skill catalog and ranking

Reviewed snapshot: 2026-10-17. Scope: native `SKILL.md` files under the installed `~/.agents/skills`, `~/.codex/skills`, and `~/.codex/plugins/cache` trees. The snapshot contained 232 files and 225 unique frontmatter names. Seven embedded `.cursor`/`.openclaw` alternate copies were excluded; they are not additional Codex skills.

## How to read the ranking

- Skills are ranked inside their primary domain; `A` is strongest project fit, `B` is useful for a matching planned task, `C` is adjacent or narrow, and `D` is outside the current stack or workflow. Project-priority order breaks ties among core/conditional selections; other ties are alphabetical. Every skill name from the inventory appears once.
- Fit considers Attestara’s actual React/TypeScript web shell, planned Go verifier, local-first delivery, source/evidence requirements, and the owner restriction against database schema, migration, `.env`, and Dockerfile changes.
- `A` skills are vendored for teammate use. `B`/`C`/`D` skills are cataloged but not bundled. Load only one primary and at most two supporting local skills when a task needs them; do not treat skill guidance as stronger than user instructions, this repository’s `AGENTS.md`, architecture decisions, or the selected Cxx card.
- “When” is a compact summary of the installed skill trigger/description, not a claim that its external tools are available. Confirm required permissions, services and dependencies before invoking them.

## Project usage rule

The selected skills are local reference material, not automatic permission to run their tools or broaden a task. Read the full selected `SKILL.md` and needed local references at task start. Preserve the plan-card boundary, open-source/local-first constraints, truthful evidence, and protected files. For API/security tools that require a live target, credentials, external service, or paid account, first confirm that the task and authorization explicitly permit that dependency; such tools are never a required Attestara runtime.
